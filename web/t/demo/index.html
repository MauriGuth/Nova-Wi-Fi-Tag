iPhone / iPad Tu equipo

Si tocaste el sticker con el iPhone, arriba apareció la tarjeta Nova Wi-Fi: toca Abrir y después Conectarme. Si no apareció, instala el perfil:

Instalar perfil Wi-Fi
  1. Toca Permitir cuando Safari pregunte por el perfil.
  2. Abre Ajustes: arriba aparece Perfil descargado. Tócalo.
  3. Toca Instalar, pon tu código y confirma.
  4. Listo: el iPhone se conecta solo a la red.

Va a decir “No firmado”: es normal. El perfil solo agrega la red Wi-Fi y puedes borrarlo cuando quieras desde Ajustes → General → VPN y gestión de dispositivos.

Android Tu equipo

Si tocaste el sticker, tu teléfono ya te preguntó si quieres conectarte. Si no apareció nada: copia la clave arriba, entra a Ajustes → Wi-Fi y elige la red.
